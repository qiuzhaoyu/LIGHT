# Scripts

## Available

- `run_retrieval_demo.py`: runs a deterministic toy example of the public
  hierarchical-retrieval reference implementation.

```bash
python scripts/run_retrieval_demo.py
```

The demo uses synthetic embeddings only. It verifies the released inference
flow without exposing clinical data or depending on an unreleased checkpoint.
