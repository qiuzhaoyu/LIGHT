# LIGHT Coarse-Region Vocabulary

This directory contains the public coarse-region vocabulary overview used by
LIGHT. It follows the 21-region hierarchy described in the manuscript.

## Files

- `coarse_regions_21.csv`: the 21 coarse regions shown in manuscript Fig. 2.

## Manuscript alignment

The 21 coarse regions match the hierarchy shown in manuscript Fig. 2.

## Privacy

This directory contains anatomical vocabulary entries only. It does not include
case IDs, report text, diagnoses, disease categories, image paths, dates, or MRI
sequence names.
